# e-plantShopping — Paradise Nursery

**Paradise Nursery** is an online houseplant shop built with React and Redux Toolkit.
The application lets users browse a curated catalogue of indoor plants grouped by
category, add them to a shopping cart, adjust quantities, and review the total cost
before checkout.

## Repository

This project lives in the public GitHub repository **`e-plantShopping`**.

## Features

- **Landing page** with a welcome message, background image and a *Get Started* button.
- **Product listing page** with plants grouped into categories (e.g. Aromatic Plants,
  Medicinal Plants, Air Purifying Plants). Each card shows a thumbnail, name,
  description, price and an *Add to Cart* button that disables after the item is added.
- **Navigation bar** visible on every page with links to Home, Plants and Cart,
  plus a cart icon that dynamically shows the total number of items.
- **Shopping cart page** with a card per plant type showing thumbnail, name, unit price,
  quantity controls (+ / −), item subtotal and a *Delete* button.
- **Totals** for each plant type and for the whole cart, recalculated in real time.
- **Continue Shopping** button to return to the product listing.
- **Checkout** button that currently shows a "coming soon" message.
